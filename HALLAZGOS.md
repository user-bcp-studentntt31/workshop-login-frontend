# Matriz de hallazgos

Todos los casos sembrados en `RETO.md` fueron contrastados con el código actual.
Los casos compuestos se separaron para permitir su seguimiento individual. La
presencia de las versiones de dependencias está confirmada, pero la existencia
de CVEs concretos queda pendiente de una auditoría especializada.

| id | hallazgo | tipo | explicacion | evidencia (archivo:linea) | severidad | estado |
|---|---|---|---|---|---|---|
| H-01 | Token de autenticación almacenado en `localStorage` | Vulnerabilidad | Los scripts que se ejecuten en el mismo origen pueden leer el token persistente. Una inyección de contenido podría exponer la sesión del usuario. | `src/app/login/login.component.ts:47`; `src/app/dashboard/dashboard.component.ts:36` | alta | Pendiente |
| H-02 | Mensaje dinámico renderizado con `[innerHTML]` | Vulnerabilidad | El mensaje combina el usuario ingresado y texto recibido del backend antes de renderizarse como HTML. Aunque Angular aplica sanitización por defecto, confiar en contenido dinámico como HTML amplía el riesgo ante cambios futuros o una omisión de esa protección. | `src/app/login/login.component.ts:55`; `src/app/login/login.component.html:39` | alta | Pendiente |
| H-03 | Componentes concentran URLs, HTTP, sesión y navegación | Refactor | Los componentes realizan solicitudes, conocen endpoints, manipulan almacenamiento y deciden la navegación.
